# Cybersecurity Management Toolkit — Public Demo

Independent, static **read-only demonstration** of the M01–M12 module portfolio. The interface is an illustrative showcase, **not** a deployment of the private Cybersecurity Management Toolkit Python engine. All displayed records and counts are synthetic, manually authored examples; do not interpret them as results produced by or imported from the private application.

## Preview locally

Open `index.html` in a modern browser. No build, server, installation, external library, or network request is required. On GitHub Pages, set **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** once the repository is created and these files are committed.

Typical GitHub Pages URL, once enabled:

`https://benatich.github.io/cybersec-management-toolkit-demo/`

## Security and privacy properties

- Standalone HTML/CSS/JS; no backend, APIs, cookies, storage, analytics, remote scripts or fonts.
- No source code or git history from the private repository is bundled.
- Displays only fictional, non-identifying demonstration values.
- UI exposes no export, file download, editing, upload, or authentication controls.
- Visitors can **always inspect and save public site assets and visible synthetic content**. GitHub Pages cannot prevent that.
- Content Security Policy blocks external connections and scripts; browsers may vary in handling CSP delivered via meta element.
- No security monitoring, scanner, credential check, incident automation, or live compliance functionality.
- For public release, manually inspect all four files and repository settings before publishing.
